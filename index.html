What is inside

Labs is organized by what you want to do, not by who built it. Start with the area closest to your task.

Brand stylesColors, typography and logo guidance. SkillsPackaged instructions that teach Claude how Uplight works. ProductsProduct facts and messaging. TemplatesStarting points for decks, pages and documents. PromptsTested prompts for everyday marketing work. ResourcesGuides, links and reference material.

Anatomy of a skill

A skill is a folder Claude reads before it starts a task. Instructions live in one file and everything else is optional, so a brand skill can carry logos, fonts and rules in one package.

typical layout
uplight-brand/
├── SKILL.md          instructions Claude reads first
├── assets/           logos, fonts, patterns
└── references/       longer guidance, loaded on demand

Built for Claude workflows

Every page in Labs is plain, structured text. Use Copy page at the top of any page to grab it as Markdown and drop it into a Claude chat or project as context.

Access

Uplight Labs is an internal resource for the corporate marketing team and the wider Uplight team. Brand assets, including the MarkOT typeface, are licensed for internal use only.

Three steps

1
Find what you need

Browse the Skills catalog or the Brand section for the asset or workflow you want.

2
Bring it into Claude

Add the skill to your Claude account, or use Copy page to paste a guide into a chat as context.

3
Ask for the work

Describe the deck, page or asset you need. Claude applies the brand rules as it builds.

Setup

Components read a few CSS variables, so they follow light and dark automatically. Copy these into your page first.

tokens.css
:root{
  --bg:#fff; --surface:#fafafb; --border:#e6e6ea; --borderStrong:#cfcfd8;
  --text:#0d0d12; --muted:#5f5f6b;
}
:root[data-theme=dark]{
  --bg:#0e0c13; --surface:#15131c; --border:#26232f; --borderStrong:#3b3748;
  --text:#f4f3f7; --muted:#a5a2b3;
}
